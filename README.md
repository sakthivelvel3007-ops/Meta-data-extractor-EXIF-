Metadata Extractor

Author: Sakthivel K

Project Description

The Metadata Extractor is a Python program that extracts and displays information about a text file. It provides file details and text statistics, helping users understand the contents and properties of a file.

Objectives

- Extract file information.
- Display the file name and file size.
- Show the last modified date and time.
- Calculate the word count, line count, and character count.
- Display the contents of the text file.

Technologies Used

- Python
- "os" module
- "datetime" module

Features

- Checks whether the specified file exists.
- Validates whether the file is a text file (".txt").
- Retrieves file information.
- Counts words, lines, and characters.
- Displays the complete file content.

How to Run

1. Install Python on your computer.
2. Save the Python code in a file named "metadata_extractor.py".
3. Run the program.
4. Enter the path of the text file when prompted.
5. View the extracted metadata and text statistics.

Expected Output

The program displays:

- File name
- File type
- File size in bytes
- Last modified date and time
- Word count
- Line count
- Character count
- File content

Conclusion

The Metadata Extractor is a simple Python project that demonstrates file handling, metadata retrieval, and text analysis. It helps users obtain useful information about text files efficiently.
